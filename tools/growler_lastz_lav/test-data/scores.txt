# WHAT CHANGED from cannabis_chiaromonte_b85-95.lastz (now superseded):
#   1. the training segments are COLINEAR-FILTERED -- Chiaromonte et al. (2002) §2 retains "only
#      the matched segments that occur in the same order and orientation in both species", a step
#      this project had skipped. Measured to separate orthologous from paralogous chromosome pairs
#      by 18x at one chain per pair; see reports/chain_cap_sweep_2026-09-15.log for why one.
#   2. annotated CDS is excluded from the REFERENCE, as her §2 deletes protein-coding segments.
#      Measured immaterial (it moves cells 1-3 points) -- kept because it is the paper's step.
#   3. counts are SYMMETRISED by Figure 1's four infers, which is her default. Also measured
#      immaterial here; the asymmetry it averages away was settled as assembly-comparability bias
#      in reports/strand_asymmetry_settled_2026-09-15.md.
#
# WHY IT REPLACED THE PREVIOUS MATRIX. Held-out evaluation by her §3 corner-threshold protocol on
# Cb2 chr1 x cs10 chr1 -- NEITHER genome trained it. It beat the superseded matrix in both regimes
# tested: 39-1 unmasked at 20 Mb, and 30-10 with the reference masked at 1 Mb (her scale), where
# the margin is 4.4-13.5%. It also beat HOXD70 and the +-100/-100 unit matrix.
# Full record: reports/heldout_evaluation_2026-09-15.md.
#
# ✅ PAIR THIS WITH LASTZ's ENTROPY ADJUSTMENT AT USE TIME -- `noentropy=false`. Settled
# 2026-09-17 by a 2x2 (masking x entropy) under this matrix, gapped, hspthresh 3000, on the
# held-out Cb2 x cs10 pair:
#
#     arm                     correct   incorrect  correct%
#     masked,   entropy OFF   544,788     483,044    53.00%
#     masked,   entropy ON    542,457     410,260    56.94%
#     unmasked, entropy OFF   797,137   3,063,423    20.65%
#     unmasked, entropy ON    793,580   2,834,702    21.87%
#
# Entropy costs ~0.44% of correct and removes 7-15% of incorrect. Masking removes 84.2% of the
# noise and entropy a further 15.07% of WHAT SURVIVES -- a larger relative bite than the 7.47% it
# takes unmasked, so the two COMPLEMENT rather than substitute.
#
# ⛔ THE OPPOSITE CLAIM USED TO STAND HERE and does not replicate: "entropy won unmasked 35-5 and
# LOST masked 14-26, so it substitutes for masking". That test predated this matrix, ran GAP-FREE,
# and was scored by a bare win/loss tally -- the statistic shown to invert when the corner curves
# cross. Full record: reports/entropy_2x2_2026-09-17.md.
#
# ⛔ BUT KEEP IT OFF FOR TRAINING -- `noentropy=true` when deriving a matrix, because entropy
# preferentially discards low-complexity segments at a fixed threshold and so biases the
# composition of the training set. Every census behind THIS file used noentropy=true, which
# remains correct; no derivation is invalidated.
#
# ⚠ CONFOUND TO CARRY: at fixed hspthresh, entropy-on is effectively more stringent (blocks drop
# 31-36%), so part of the noise reduction is stringency rather than discrimination. The corner
# protocol controls for it and agrees, but crosses 12 times -- two weak instruments agreeing, not
# one strong result.
#
# ⚠ OPEN: this matrix was DERIVED under noentropy=true; nobody has checked whether it would come
# out differently if training used entropy.
